# 🌿 Plant Disease Detection System

This project detects tomato plant diseases using deep learning.

## 📌 Features

* Image-based prediction
* Real-time camera detection
* Uses MobileNetV2 model

## 🧠 Technologies Used

* Python
* TensorFlow
* OpenCV

## ▶️ How to Run

### 1. Install dependencies

```
pip install tensorflow opencv-python numpy
```

### 2. Train model

```
python train.py
```

### 3. Predict from image

```
python predict.py
```

### 4. Live camera detection

```
python camera.py
```

## 📂 Dataset

Download dataset from Kaggle and place inside `dataset/` folder.

## 🎯 Output

* Predicts: Bacterial Spot, Early Blight, Healthy
